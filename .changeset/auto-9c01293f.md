strip the Apollo Router's `__<subgraph>__<index>` suffix from operation names before recording them, so the portfolio SystemStats operations table (and the CloudWatch OperationCount metric for portfolio/pantry/imposter) shows "Footer" instead of "Footer__portfolio__0". The federated query planner renames every subgraph-level operation this way for its own internal tracing, even for single-subgraph queries, which had also silently broken the plugin's IntrospectionQuery/TraceBreakdown/SystemStats ignore list.
